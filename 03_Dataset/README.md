# Dataset Documentation

## Project

**PediVision AI — Multimodal Analysis of Pediatric MRI Images**

## Purpose

This folder documents the datasets considered for the research project, including their sources, access requirements, data structure, and suitability for pediatric brain tumor classification using MRI and clinical information.

## Potential Dataset

### Children's Brain Tumor Network (CBTN)

* **Dataset:** Children's Brain Tumor Network (CBTN)
* **Purpose:** To investigate whether combining MRI-derived features with clinical information can improve pediatric brain tumor classification.
* **Access status:** Not yet confirmed.
* **Data availability:** To be verified.
* **Target labels:** To be determined after reviewing the dataset documentation.
* **Clinical variables:** To be determined after reviewing the available data.

## Data Access and Privacy

* Dataset access requirements and permissions must be verified before use.
* Only authorized and appropriately de-identified data will be used.
* Patient-level data must not be uploaded to this public GitHub repository.
* Dataset terms and ethical requirements must be followed.

## Data Preparation

After obtaining authorized access, the following steps will be documented:

1. Review the dataset documentation and data dictionary.
2. Identify available MRI sequences and clinical variables.
3. Identify the classification target and eligible patient records.
4. Check missing values and data quality.
5. Define patient-level training, validation, and test splits.
6. Document preprocessing and quality-control procedures.
