# Data Dictionary

## Project

**PediVision AI — Multimodal Analysis of Pediatric MRI Images**

## Purpose

This document records the meaning, format, and availability of the variables used in the research dataset.

**Important:** The fields below are a documentation template. Actual variables must be verified using the official dataset documentation.

## MRI Data

| Field              | Description                        |
| ------------------ | ---------------------------------- |
| MRI Record ID      | Identifier for an MRI record       |
| Patient ID         | De-identified patient identifier   |
| MRI Sequence       | Type of MRI sequence, if available |
| Image Format       | Format of the MRI image files      |
| Image Availability | Whether the MRI image is available |

## Clinical Data

| Field              | Description                                   |
| ------------------ | --------------------------------------------- |
| Patient ID         | De-identified patient identifier              |
| Age                | Patient age, if available and authorized      |
| Clinical Variables | Clinical information available in the dataset |
| Diagnosis          | Recorded diagnosis, if available              |
| Target Label       | Classification label selected for the study   |
