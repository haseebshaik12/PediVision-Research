## 3. Research Objective
The objective of this research is to investigate whether integrating MRI-derived features with structured clinical information improves pediatric brain tumor classification compared with MRI-only and clinical-only models.

## 4. Dataset Requested
- Dataset: Children's Brain Tumor Network (CBTN)
- Requested resources: Pediatric brain MRI scans and associated clinical information, subject to availability and approval.
- Target population: Pediatric brain tumor patients.
- Intended task: Classification of selected brain tumor subtypes.

## 5. Requested Data Elements

### Imaging Data
- Available MRI sequences, such as T1w, T1w post-contrast, T2w, and ADC.
- Imaging data linked to individual patients.
- Imaging metadata needed for preprocessing and analysis.

### Clinical Data
- Patient age at imaging, if available.
- Tumor diagnosis and subtype.
- Other relevant structured clinical variables, if available and approved.

## 6. Proposed Research Methodology
1. Review the approved dataset and assess data quality.
2. Establish an MRI-only classification baseline.
3. Establish a clinical-only baseline if suitable variables are available.
4. Develop a multimodal model combining MRI-derived features and clinical variables.
5. Compare model performance using consistent patient-level data splits.
6. Evaluate classification performance using appropriate metrics.
7. Investigate missing-modality robustness if the dataset supports it.
