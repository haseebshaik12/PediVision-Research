
# PediVision Dataset Feasibility Assessment

## 1. Proposed Dataset
- Dataset name: Children's Brain Tumor Network (CBTN)
- Intended use: Pediatric brain tumor classification using MRI and clinical information
- Access status: Not yet confirmed

## 2. Required Data

### MRI Data
- MRI scans linked to individual patients
- Available MRI sequences, such as T1w, T1w post-contrast, T2w, and ADC
- Scan quality and completeness
- MRI scan availability across tumor classes

### Clinical Data
- Patient age
- Tumor diagnosis and subtype
- Other structured clinical variables, if available
- Missing values and data completeness

### Patient-Level Information
- Unique patient identifiers for linking MRI and clinical records
- Multiple scans per patient, if applicable
- Sufficient information to create patient-level training and testing splits
